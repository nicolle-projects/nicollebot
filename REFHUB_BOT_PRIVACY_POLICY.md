# RefHub Bot - Privacy Policy

Last updated: 2026-10-11

## Overview
RefHub Bot is a **private tool** run by its owner in the owner's private test servers.
It is **not available to the public**.

## What RefHub Bot reads
RefHub Bot reads messages in those servers **only to notice commands**.
Messages that are not commands are not saved or logged.

## What is sent when the save feature is used
When the owner uses the save feature (`!save`, also `!kb`), RefHub Bot sends the following to **RefHub**, a private staff web app, for review:

* The message text (and any note typed with it)
* The author's display name
* The channel name
* A link to the message
* The message ID

Nothing is sent unless the save feature is used.

RefHub Bot also sends RefHub its own status (bot name, version, and start time). No user data is included.

Some staff-only features exchange limited data with the same private staff app and are not available to regular members.

## What RefHub Bot stores itself
RefHub Bot has no database of its own and does not keep message text in its logs.

## Data sharing
RefHub Bot does **not sell or share** data with advertisers or analytics services.
It talks only to Discord and RefHub.
RefHub is hosted with commercial web hosting and database providers.

## Data removal requests
To ask for something that was saved to be removed, contact the bot owner (see below).

## Children’s privacy
RefHub Bot is **not intended to collect personal information from children**.

## Changes to this policy

If RefHub Bot's data handling changes, this policy must be **updated before deploying the modified system**.

## Contact and Identity Verification

For privacy requests, security concerns, or data removal, please contact the bot owner. RefHub Bot does not provide email-based support to prevent impersonation and maintain Discord-verified communication.
